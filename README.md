# Loto

Ce projet analyse les tirages du loto à partir de fichiers CSV et génère des statistiques basées sur les tirages passés. 
Il permet d'analyser les fréquences des boules tirées, de calculer les probabilités et de trouver les meilleures combinaisons en fonction des tirages précédents.
